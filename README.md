# Rajzolt kamiontérkép

Rajzolt navigációs térkép Magyarország teljes területére, kamionszimulátor módjára. Az ország körvonala, a folyók és a városok kézzel rajzolt térképként látszanak. Az induló hely és a cél is cím szerint kereshető, az útvonal pedig animálva rajzolódik fel.

Nyisd meg az `index.html` lapot. A lépések a `HOW_TO_START.md` fájlban vannak.

A címkeresés a Photon szolgáltatást, a két cím közötti út a FOSSGIS OSRM szolgáltatást használja. A kiírt kilométer és idő ezekből a válaszokból származik. A korábbi arcade lap az `elozo-arcade.html` fájlban maradt.
