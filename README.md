# Rajzolt kamiontérkép

Rajzolt navigációs térkép Magyarország teljes területére, kamionszimulátor módjára. Az ország körvonala, a folyók és a városok kézzel rajzolt térképként látszanak. Egy magyar címre az útvonal animálva rajzolódik fel.

Nyisd meg az `index.html` lapot. A lépések a `HOW_TO_START.md` fájlban vannak.

A címkeresés a Photon szolgáltatást, a címhez tartozó út a FOSSGIS OSRM szolgáltatást használja. A kiírt kilométer és idő ezekből a válaszokból származik. Két város között a berajzolt úthálózat adja az utat. A korábbi arcade lap az `elozo-arcade.html` fájlban maradt.
