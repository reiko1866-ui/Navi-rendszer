# ToonNav3D

Rajzfilmes 3D-s minta, böngészőben. A K706 fekvő képernyőjére készül.

Nyisd meg az `index.html` lapot. Egy piros autó megy egy mintakörön, a kamera mögötte és fölötte van. Az Éjszaka gomb sötétre váltja a képet, a Nappal vissza. A Megáll megállítja az autót, a Megy újraindítja.

Ez még nem navigáció. Nincs benne GPS, címkeresés és útvonaltervezés.

A korábbi térképes lap megmaradt: `elozo-terkep.html`.
