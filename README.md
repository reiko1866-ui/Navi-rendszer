# ToonNav3D

A K706 képernyőjére készül.

Nyisd meg az `index.html` lapot. Az Ahol vagyok a GPS-helyzet. A keresőbe írd a pontos címet, ahova mennél, és válaszd ki a címjegyzékből. Az Indítás után a térkép marad. A távolság csak akkor csökken, ha az autó a GPS szerint elindul.

Álló és fekvő képernyőn is működik.
